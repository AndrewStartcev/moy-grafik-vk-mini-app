# Мой график — VK Mini App

Полезное мини-приложение ВКонтакте для людей со сменным графиком работы.

Пользователь выбирает тип сменного цикла и дату начала, после чего приложение автоматически строит календарь, показывает текущий статус, следующую смену и статистику месяца.

## Статус

**Этап:** первый функциональный MVP и UI-проход.

Уже реализованы domain engine, onboarding, календарь, статистика, ручные исключения, настройки времени смен, VK Storage с localStorage fallback, аналитический abstraction и CI quality gate.

Следующая контрольная точка после тестирования владельцем продукта: полировка UI → полноценная VK integration → реклама.

## Локальный запуск

Требуется Node.js 22.12+.

```bash
npm install
npm run dev
```

Vite по умолчанию откроет приложение на:

```text
http://localhost:5173
```

Обычный браузер поддерживается специально: если приложение запущено не внутри VK, данные сохраняются через `localStorage`, а ошибки VK Bridge не блокируют работу.

## Проверки качества

```bash
npm run typecheck
npm run lint
npm run test
npm run build
```

Те же проверки выполняются в GitHub Actions при push в `main`.

## MVP

- готовые циклы: `2/2`, `3/3`, `5/2`, `сутки/трое`, `день/ночь/2 выходных`;
- произвольный повторяющийся цикл;
- дата начала цикла;
- календарь по месяцам;
- дневная, ночная, суточная смена и выходной;
- ручное переопределение отдельного дня;
- отпуск и больничный как исключения;
- карточка «Сегодня»;
- следующая смена;
- статистика месяца;
- сохранение данных;
- VK Mini Apps integration;
- реклама;
- аналитика;
- светлая и тёмная темы.

## Не входит в первый релиз

- авторизация вне VK;
- собственный backend;
- расчёт зарплаты;
- производственный календарь;
- уведомления и будильники;
- экспорт PDF/ICS;
- синхронизация с внешними календарями;
- несколько графиков;
- общий график партнёров;
- покупки;
- AI.
