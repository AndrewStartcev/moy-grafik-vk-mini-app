# UI review — 2026-09-11

Текущий визуальный подход принят как базовое направление. Полный редизайн не нужен: дальше только polishing-pass поверх существующей архитектуры экранов.

## Что оставляем

- единый utility-app стиль;
- текущую структуру главного экрана;
- карточку текущей смены;
- месячный календарь;
- блок статистики;
- текущую структуру настроек;
- onboarding из выбора шаблона + даты начала;
- Lucide как единый набор интерфейсных иконок.

## Что нужно отполировать после функциональной проверки

1. Уменьшить визуальную тяжесть крупных белых карточек и границ.
2. Уплотнить onboarding примерно на 20–30%, чтобы CTA был выше первого экрана.
3. Упростить календарные ячейки и снизить текстовый шум `Д / В`, если цвет и легенда уже однозначно передают состояние.
4. Сделать статистику визуально легче относительно календаря.
5. Проверить вертикальные отступы и плотность на ширинах 320–360 px.
6. Настройки приблизить к нативному списку секций: меньше ощущения «карточка в карточке».
7. Не менять направление дизайна без отдельной причины — улучшать текущую систему последовательно.

## Логотип приложения

PNG `public/app-icon.png`, который использовался в интерфейсе, в браузере отображался пустым/прозрачным. UI больше не зависит от PNG: `AppIcon` рендерится программно как SVG/Lucide-компонент с фирменным синим контейнером. Favicon также переведён на `public/favicon.svg`.

PNG для карточки приложения в VK будет подготовлен/проверен отдельно перед релизом и не должен использоваться как критическая runtime-зависимость интерфейса.
