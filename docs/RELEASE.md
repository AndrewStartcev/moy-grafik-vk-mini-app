# Release & moderation checklist

Документ заполняется конкретными ID/URL перед релизом.

## 1. До создания production release

- [ ] MVP scope заморожен
- [ ] owner acceptance пройдена
- [ ] `npm run typecheck` pass
- [ ] `npm run lint` pass
- [ ] `npm run test` pass
- [ ] `npm run build` pass
- [ ] browser fallback работает
- [ ] VK desktop проверен
- [ ] VK mobile проверен
- [ ] light/dark проверены
- [ ] storage проверен
- [ ] ads failure не ломает приложение

## 2. VK application

Нужно зафиксировать:

```text
VK App ID: TBD
Production URL: TBD
Development URL / tunnel: TBD
```

Настройки VK выполняются владельцем аккаунта там, где требуется его авторизация. Разработчик даёт точные значения и последовательность действий.

## 3. Каталожные материалы

Подготовить:

- [ ] Название: `Мой график — календарь смен`
- [ ] Короткое описание
- [ ] Полное описание
- [ ] Иконка
- [ ] Обложка/промо-графика при необходимости
- [ ] Скрин первого запуска
- [ ] Скрин календаря
- [ ] Скрин редактирования дня
- [ ] Скрин настроек

## 4. Legal / privacy

Перед отправкой на модерацию повторно проверить актуальные требования VK.

Если требуются URL:

- [ ] Privacy Policy
- [ ] User Agreement / Terms
- [ ] Contact/support information

Не собирать данные, которые продукту не нужны.

## 5. Advertising

- [ ] рекламный кабинет/placement настроен
- [ ] используемые форматы разрешены для приложения
- [ ] banner доступность проверяется до показа
- [ ] interstitial availability проверяется до показа
- [ ] frequency cap включён
- [ ] onboarding без рекламы

## 6. Storage

- [ ] первый save
- [ ] reload
- [ ] повторный вход
- [ ] fallback
- [ ] corrupt data path
- [ ] reset

## 7. Moderation smoke test

Сценарий модератора:

1. открыть приложение;
2. выбрать `2/2`;
3. выбрать сегодняшнюю дату как начало;
4. построить график;
5. перелистнуть месяц;
6. открыть дату;
7. поставить выходной;
8. открыть настройки;
9. перезапустить приложение;
10. убедиться, что график сохранён.

Этот путь должен работать без объяснений разработчика.

## 8. Release record

После публикации добавить:

```text
Release date: TBD
VK catalog URL: TBD
Version: TBD
Commit SHA: TBD
```

## 9. После публикации

В первые итерации проверять:

- ошибки запуска;
- activation;
- retention;
- storage failures;
- ad availability/errors;
- пользовательские отзывы.

Новые функции не добавлять до первичного продуктового review, кроме критических исправлений.
